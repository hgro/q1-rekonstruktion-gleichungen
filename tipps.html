Aufgabe 1: Von den Bedingungen zur Funktion

Graph 1 gehört zu einer Funktion f dritten Grades mit dem Hochpunkt H(2 | 6) und dem Wendepunkt W(0 | 2). Schreiben Sie Ansatz und Ableitungen auf, schreiben Sie jede Bedingung als Gleichung mit a, b, c, d, lösen Sie das Gleichungssystem mit dem LGS-Rechner und prüfen Sie Ihr Ergebnis.

Hilfe 1

Schreiben Sie zuerst den Ansatz f(x) = ax³ + bx² + cx + d und seine Ableitungen auf. Sie stehen in Ihrer Übersicht.

Jede Bedingung aus der letzten Stunde wird zu einer Gleichung: Sie setzen die Zahlen in die passende Ableitung ein.

Hilfe 2

  • f(2) = 6: Setzen Sie x = 2 in f(x) ein. Das ergibt a · 2³ + b · 2² + c · 2 + d = 6. Rechnen Sie die Potenzen aus.
  • f′(2) = 0: Setzen Sie x = 2 in f′(x) = 3ax² + 2bx + c ein.
  • f(0) = 2: Bei x = 0 fallen fast alle Terme weg.
  • f″(0) = 0: Setzen Sie x = 0 in f″(x) = 6ax + 2b ein.

LGS-Rechner: Wählen Sie vier Unbekannte. Fehlt eine Variable in einer Gleichung, ist ihr Koeffizient 0.

Hilfe 3: Lösung zum Vergleichen

I: 8a + 4b + 2c + d = 6
II: 12a + 4b + c = 0
III: d = 2
IV: 2b = 0

Lösung: a = −¼, b = 0, c = 3, d = 2, also f(x) = −¼x³ + 3x + 2.

Probe: f(2) = 6, f′(2) = 0, f(0) = 2, f″(0) = 0.

Aufgabe 2: Mias Lösung prüfen

Mia hat die Funktion zu Graph 2 (Hochpunkt H(0 | 0), Tiefpunkt T(2 | −4)) bestimmt. In ihrer Rechnung steckt ein Fehler. Finden Sie die Zeile mit dem ersten Fehler, erklären Sie ihn, zeigen Sie ihn mit einer Probe und korrigieren Sie die Rechnung.

Hilfe 1

Vergleichen Sie jede Zeile von Mias Rechnung mit Ihrer Übersicht. Beginnen Sie oben. Welche Zeile weicht als erste ab?

Ein Fehler kann in späteren Zeilen weiterwirken. Suchen Sie den ersten.

Hilfe 2

  • Fehler finden: Wie wird bx² abgeleitet? Vergleichen Sie mit der Zeile „Ableitung“. Welche spätere Zeile benutzt diese Ableitung?
  • Probe: Leiten Sie Mias Funktion f(x) = 1/4 x³ − 3/2 x² richtig ab. Setzen Sie x = 2 in f′ ein. Was müsste herauskommen?
  • Mias Probe: Welche der vier Bedingungen hat sie geprüft? Welche nicht?
  • Korrektur: Stellen Sie Zeile IV neu auf und lösen Sie das System mit dem LGS-Rechner. Prüfen Sie am Ende alle vier Bedingungen.

Hilfe 3: Lösung zum Vergleichen

  • Erster Fehler: Zeile „Ableitung“. Mia schreibt 3ax² + bx + c, richtig ist 3ax² + 2bx + c, weil die Ableitung von bx² gleich 2bx ist.
  • Folge: Zeile IV müsste 12a + 4b + c = 0 heißen.
  • Probe: Mit f′(x) = 3/4 x² − 3x ist f′(2) = −3 ≠ 0. Die Tangente in T ist nicht waagerecht.
  • Mias Probe: Sie hat nur f(2) = −4 geprüft, die Bedingungen mit f′ nicht.
  • Korrektur: d = 0, c = 0, 8a + 4b = −4, 12a + 4b = 0 ergibt a = 1, b = −3, also f(x) = x³ − 3x².

Aufgabe 3 (Zusatz): Noch ein Graph

Der Graph einer Funktion h dritten Grades berührt die x-Achse bei x = 1, schneidet die y-Achse bei 2 und hat bei x = −1 einen Hochpunkt. Bestimmen Sie h(x): Bedingungen, Gleichungen, LGS-Rechner, Probe.

Hilfe 1

Übersetzen Sie jede Angabe einzeln. Nutzen Sie die Tabelle „Eigenschaft → Bedingung“ aus Ihrer Übersicht.

  • „berührt die x-Achse bei 1“: Nullstelle plus waagerechte Tangente
  • „schneidet die y-Achse bei 2“: ein Punkt auf dem Graphen
  • „Hochpunkt bei x = −1“: nur die Stelle ist bekannt, also nur die waagerechte Tangente

Hilfe 2

Die Bedingungen lauten h(1) = 0, h′(1) = 0, h(0) = 2 und h′(−1) = 0.

Setzen Sie die Stellen in h(x) = ax³ + bx² + cx + d und h′(x) = 3ax² + 2bx + c ein. Aus jeder Bedingung wird eine Gleichung mit a, b, c, d.

Hilfe 3: Lösung zum Vergleichen

I: a + b + c + d = 0
II: 3a + 2b + c = 0
III: d = 2
IV: 3a − 2b + c = 0

Lösung: a = 1, b = 0, c = −3, d = 2, also h(x) = x³ − 3x + 2.

Probe: h(1) = 0, h′(1) = 0, h(0) = 2, h′(−1) = 0.
